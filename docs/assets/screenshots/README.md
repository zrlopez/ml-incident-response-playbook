# Screenshot Capture Checklist

This directory is reserved for real portfolio screenshots. Do not commit generated mockups as screenshots.

Recommended captures:

| File | Capture target | Purpose |
|---|---|---|
| `hf-anomaly-demo.png` | Hugging Face Space after one inference run | Shows the live demo surface |
| `vercel-docs-home.png` | `https://mlops.zrl.dev` home page | Shows the published Vercel documentation site |
| `ci-pipeline.png` | Latest successful Secure CI Pipeline run | Shows supply-chain/security gates |
| `grafana-overview.png` | Local Grafana dashboard from `dashboards/ml_operations_overview.json` | Shows observability maturity |
| `runbook-decision-tree.png` | Rendered Mermaid decision tree from one runbook | Shows incident response workflow |

After captures exist, embed the real PNG files from this directory in the
top-level README under `## Visual Tour`.
