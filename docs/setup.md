# Setup Instructions

## Prerequisites

- Git.
- A Markdown editor or VS Code.
- Mermaid support for diagram previews.

## Local Setup

1. Clone the repository.
2. Open the repo in your editor.
3. Review the runbooks and templates.
4. Preview Mermaid diagrams if your editor supports them.

## Recommended Workflow

- Edit one runbook at a time.
- Keep all files aligned to the same structure.
- Validate links and headings before committing.
